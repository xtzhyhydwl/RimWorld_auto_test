# RimWorld mod 流程：分阶段 + Gate

**唯一那条让它生效的规则：状态活在文件里，不活在对话里。**
每做一件事**之前**读状态文件，**之后**写回去。**不读就动手 = 这个流程已经失效了。**

## 状态文件（唯一的真相源）

路径 `docs/<mod名>-进度.md`。没有就**建**。固定骨架：

```
当前阶段：0..7
本阶段 Gate：<从下表原样抄>
Gate 的答案：<必须写成一句话或一段。写不出来 = 没过>
未确证清单：
  🔴 重构级：<猜错要改架构>
  🟡 返工级：<猜错要重写某模块>
  🟢 改名级：<猜错只改名字/数值>
本轮动过的东西：<文件 / 结论，一行一条>
下一步：
```

## 八个阶段

**按顺序走。Gate 不过就不进下一步。**

| 阶段 | 做什么 | Gate（**写得出答案**才算过） |
| --- | --- | --- |
| **0 意图澄清** | 用**拷打**问清需求（方法见下） | 能一句话答「提供什么 / 凭什么值得做 / 凭什么不破坏平衡」，且**前沿为空** |
| **1 约束与许可** | 依赖许可、发布渠道规则、目标版本、素材来源 | **没有一条约束能一票否决当前设计** |
| **2 机制侦察** | 逐个取证要用到的机制，建**符号台账**（含"不存在"清单） | 要用的符号**全部有条目**：确证 / 未确证 / 不存在（三选一） |
| **3 可行性裁决** | 列出**所有**未知量，按**猜错后果**分 🔴🟡🟢 | **没有任何 🔴** |
| **4 设计（施工图）** | 写施工图：假设标"假设"、代码标"未执行"、跨文档只用节号 | **一个不知情的读者能照它写出方案**，且它"必须猜的"里**没有 🔴** |
| **5 地基探针** | 一个**用完即弃**的最小实作，把 🔴🟡 **变成事实** | **所有 🔴 已变成事实**，且设计**已按事实更新** |
| **6 产品代码** | 6.1 骨架 → 6.2 承重行为 → 6.3 边界与解绑 → 6.4 存档往返 → 6.5 贴图 → 6.6 发布准备 | 每一小步各自的判据（见 `阶段详法.md`） |
| **7 验收与发布** | 7.1 自动化验收 → 7.2 人工验收 → 7.3 发布准备 | **自动化判据全过** + 无占位资源 + 无实验残留 |

**两个环**（流程不是直线）：

- **3 → 0**：裁决发现做不成 ⇒ 可能改的是**需求**，不只是设计
- **4 → 5 → 4**：探针**几乎总会改设计**，这是正常的，不是失败

## 漂移自检

每次更新状态文件时，回答这三句：

1. **我现在的 Gate 是什么？** —— 写不出来 ⇒ 已经在漂
2. **这一步让 Gate 变绿了吗？**
3. **没变绿的话，我做它的理由是什么？** —— 答不出 ⇒ 停下来

> **Gate 靠"写得出答案"判定，不靠"感觉差不多"。写不出来就是没过。**

## 阶段 0 的方法：拷打（设计树）

- 把需求看成**设计树**：每个决定分叉出依赖它的决定
- **frontier（前沿）** = 前提都已确定、**现在就能问**的那些问题
- **一轮只问前沿**：一次问完，每条**编号**、并**给出你推荐的答案**
- 用户答完 ⇒ 前沿外扩 ⇒ **重算前沿**，问下一轮
- **依赖本轮未答问题的问题 ⇒ 属于后面的轮次**，不要塞进本轮
- **取证是执行方的活**：能自己查到的事实**不要问用户**（派子代理去查）
- **结束条件：前沿为空。前沿空之前不许开工。**
- 完整方法用 `grilling` skill

## 详细方法（按需取，不要一次读完）

| 你要什么 | 读哪 |

| 工具给出可疑结果 / 两个工具说法不一致 | 同目录 `环境陷阱.md` |
