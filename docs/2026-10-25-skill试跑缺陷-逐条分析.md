# skill 试跑：缺陷逐条分析（给人读的版本）
> 这份和 `docs\2026-10-25-skill试跑缺陷.md` 的关系：那张是"表"，这里是"过程 + 可信度"，编号完全一致，读完这份不必再读表。
> 一句话：八项里 7 项走通（环境自检只是"部分"），但**照抄文档的命令/示例有 4 处会直接失败或付出真实代价**；45 条里真正会让人走错路的只有 8 条，其余是措辞、字段名与失效指针。
> 标签：`[A]`/`[B]`/`[C]`/`[D]`/`[编排]` = 谁跑的；置信度只有【实测】（真机/真命令）、【核对】（打开原文或源码读到）、【推测】（没人跑过）三种。

## 0 十分钟速读路径（看完这 8 条就够拍板）
1. **#1/A1** `start --help` 起 561 mod 实例 —— 唯一"只读意图付出真实代价"的一条，编排者亲手踩的，排最前。
2. **#3/C4** 命令示例普遍缺 `--profile` —— 新代理第一步 exit 1，而"补个 profile"的本能正好补到满配 vanilla，是上一条的放大器。
3. **#2/A2** `call` 动作失败仍 exit 0 —— 直接产出假结论，比崩掉更危险。
4. **#5/B2** 探针自己报错被当成"还没进图" —— 白等满超时 + 去改本来没错的字段。
5. **#4/B4** CE 的 `part` 示例在中文包下必失败，且"改对了"还会截错腿 —— 照抄不报错。
6. **B6+D8** 推时间速率被当常数 —— 预算公式系统性小 4–6 倍，3000 tick 会 timedout。
7. **A6** 登记表里 `无模态窗口` 永不成立 —— 一条永远 exit 2 的判据会让人以为游戏坏了。
8. **B8** 缺原子模板少了"等价性"一问 —— 它决定"补数据还是补采样层"，两个代理会给相反答案。
