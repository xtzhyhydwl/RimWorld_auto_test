## 2 现象【用户目视实测】

1. 围攻开始后只有**成年来客**有进攻动作；儿童原地闲逛，即使整体是敌对状态。
2. 殖民者被打死后食物落在地上，成年来客去吃；**儿童不吃**，一直闲逛到饿死。
3. 婴儿不在此列（婴儿本来不该战斗）；问题只在**儿童（Child）**。
4. 用户补充："儿童好像被赋予了什么事都不会做的状态。"

## 3 已查到的链路【静态实测，行号对 `d699404`】

1. **来客只有一个 job giver**：`1.6`/`1.7` 的 `Defs\ThinkTreeDefs\RHAH_ThinkTrees.xml` → `RHAH_VisitorFallback`，插在 `Humanlike_PostDuty`（priority 100），根节点 `ThinkNode_ConditionalRHAH_Visitor`（条件 = `RHAH_BatchAttitude.CanOrderLeave(pawn)`），**子节点只有 `JobGiver_RHAH_Visitor`**。
   ⇒ 来客的全部行为都从这一个 giver 出；它返回 `null` 就掉回原版 post-duty 节点 ⇒ 表现就是"原地闲逛"。
2. **参战闸门明确只让成人打**：`Source\Pawn\JobGiver_RHAH_Visitor.cs:43` `CanFight`，第 **52 行** `pawn.DevelopmentalStage.Adult()`，同一表达式还要求 `Attitude == Hostile`、`Faction.HostileTo(player)`、`Allows(Fight)`、`!WorkTagIsDisabled(Violent)`。儿童在 `Adult()` 这一条就出局。
3. **`Fight` 闸门默认规则排儿童**：`Source\Identity\RHAH_PawnDefaults.cs:34-36` = `role == Siege || attitude == Hostile`；儿童角色（`RHAH_PawnRole.BeggarChild/ThiefChild/WildChild/RatkinYoung`）永远不是 `Siege`。
4. **批量下令也逐个排儿童**：`Source\Pawn\RHAH_BatchAttitude.cs:107`、`:135` 按成员查 `Allows(Fight)`。
5. **发武器同样要求成人**：`Source\Generation\RHAH_FamineWeapons.cs:29`、`:38`（这条是合理的，不用改）。
6. **吃这条路在别处**：`Source\Pawn\JobGiver_RHAH_Feed.cs`（`TryCreate` 从 :19 起）。它先看 `RHAH_ReliefFood.MayEatOutside(pawn)` 决定"能不能吃救济区外的东西"（:72 `insideOnly`），儿童还有专门的"趴地上吃"分支：`Source\Pawn\RHAH_ReliefFood.cs:173` → `RHAH_ChildMovement.EatsOnFloor`（`Source\Pawn\Compat\RHAH_ChildMovement.cs:78`，manipulation stage == 1）。
   ⇒ **儿童吃饭是有实现的**，"不吃"更可能是被救济区/态度规则挡住，或压根没走到这个 giver。**这一半纯静态推不出来。**
