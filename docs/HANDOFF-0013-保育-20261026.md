## 4 关键约束（定案，不许"优化"）

- 保育排在工作队列**最前**，但**让位给战斗与离场**（插入点 = 现在 `JobGiver_RHAH_MotherFeed` 的位置）。
- **人人可保育，含儿童**；不设亲属、不设 Manipulation 门槛。
- 保育者**不吃婴儿食物**（`babiesCanIngest` 动态判据），**唯一例外** `Malnutrition.Severity >= 0.7`。
  ⚠ **不能**用饥饿值百分比当例外判据——来客刷出来就是饥饿 0 + 营养不良，那样等于人人放行。
- 记账 = **交付即记账**；婴儿目标 **0.48 营养**（成人 2.4 × 0.2）。
- 投喂婴儿 → 交给**离点击殖民者最近的可行动来客**；**没有可行动成员就直接给婴儿本人**（他能吃就吃，不另开分支）。
- 保育取食**遵守**赈灾区禁用名单（`GiveFoodAllowed`）；`allowImmobileBabies` 保留否决权。
