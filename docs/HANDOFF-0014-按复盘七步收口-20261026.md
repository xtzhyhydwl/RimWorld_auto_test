## 4 每一步都适用的纪律（违反即停）

1. **一次只开一票**；同一会话不连做两票。
2. **一票 ≤3 个新文件**（票面状态 / 1 份验证报告 / PR 正文）。其余内容写进票的对应小节。
3. **中文落盘只用 `write`/`edit` 工具或 `cli … --out`**；写完用 `text-check` 验。
4. **写探测脚本前先问用户**（一次性 → 用完即删；长期 → 进统一入口）。派子代理时把这条写进它的提示词。
5. **不 `stop --force`**（会杀用户正在玩的局）；**不 push `origin`**；**不 `git add` 那 4 个 DLL**。
6. **不在决策票正文里开工**——先有实施单/实施票再动手。
7. **提交前必跑** `python scripts/rhah_pipeline.py check`（0002 的 CI 首次红就是只跑了 build）。
8. 结论**当场**落盘（进度写回**票面 `## 状态`**；机制进 `docs/`；经验进 skill），别留到最后。**`STATUS.md` 不记状态**。
