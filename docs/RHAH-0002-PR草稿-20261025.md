## 问题

乞食围攻的来客有一天的围攻期限，但他们到场时就已经带着中度的营养不良,一天期限还没到，人先全饿倒了, 围攻变成了单方面挨饿，所以我决定把「乞食围攻」这一种情况单独处理。顺带为了让它更有意思，我给这批来客加了个特性：**营养不良越重，被赋予越高的数值, 进攻越凶猛**；再配一份心情加成，避免围攻期间自己先精神崩溃。

## 做法

来客到场先清空营养不良，让他们从 0 重新开始攒，并挂一个专门的 buff；buff 按营养不良 **0.25 / 0.50** 分三档，档位决定 hediff severity **0.10 / 0.50 / 0.90** 与加成强度：近战命中、近战伤害、出手间隔、闪避、承伤、耐痛、移速、意识逐档递增，并分别给 **40 / 50 / 60** 的心情（就是上面说的防崩溃那部分）。buff 固定 **两日（120000 tick）** 后自行消失。**不压营养不良上限**——原版 0.8 / 1.0 的后果照常发生，只是他们更抗得住。

## 改动

- **23 个文件 = 新增 7 + 修改 16**：新增 1.6 / 1.7 两份 `Defs/HediffDefs/RHAH_SiegeFury.xml`、三个源文件（`Generation/RHAH_SiegeFuryGrant.cs`、`Pawn/HediffComp_RHAH_SiegeFuryStage.cs`、`Tests/RHAH_SiegeFuryTests.cs`）、英/日两份 `Languages/*/DefInjected/HediffDef/RHAH_SiegeFury.xml`；修改 8 个源文件（DefOf / 设置 / 到场清饥饿 / 武器 / PawnFactory / IrisMenus 适配 / 心情）、2 份 `RHAH_Famine.xml`（三条心情）、英/日两份 `DefInjected/ThoughtDef/RHAH_Famine.xml`、3 份语言文案、`save-ownership.md`（补 `siegeFuryEnabled` 归属）；
- 新增 **1 个设置开关 `siegeFuryEnabled`**（默认开，位置在 IrisMenus 事件页「索粮围攻」组头）：关掉即一次性停掉本功能的全部效果，含心情。
