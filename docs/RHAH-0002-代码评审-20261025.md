## 2 分层（口径 2）

原来的层次长什么样（实测）：心情的入口是 `Source/Pawn/RHAH_VisitorMood.cs:48-58`，`Memories(pawn)` 统一做三道闸门（`famineMoodEnabled`、有来客快照 `CompRHAH_Pawn.TryGet`、`RHAH_Race.IsRatkin`），`NotifyEnslaved`（`:21-30`）示范了「先删旧两档再挂新档」；`RHAH_FamineMood.cs:10-15 NotifyFed` 是同一形状的极简版。心情类（`Thought_Memory_*`）都写在心情文件里：`RHAH_FamineMood.cs:51`、`RHAH_VisitorMood.cs:87`。

- **L1【硬违规】ThoughtDef 类塞进了 HediffComp 文件。** `CompRHAH_EnduranceTier.cs:93-98` 在 comp 类闭合后追加 `public sealed class Thought_Memory_RHAH_SiegeFury`。撞 `Source/AGENTS.md` 明文「文件名与主类型一致…一个文件一个主概念，相关枚举可同文件」——它不是枚举，是 Def 反射入口。原代码的层次是「心情类放心情文件」（`RHAH_VisitorMood.cs:86-90` 就是同形类）。改法：搬到 `RHAH_FamineMood.cs`（`Thought_Memory_RHAH_FamineFed` 同文件）或 `RHAH_VisitorMood.cs`，XML 三处 `thoughtClass` 与 `save-ownership.md:267` 同步。
- **L2【判断】心情逻辑绕过了模块入口。** 新代码自己在 comp 里拼 `Pawn?.needs?.mood?.thoughts?.memories`（`:74`、`:81`），三道闸门一道都不过；`NotifyEnslaved` 那套「先删再挂」也重写了一遍（`:79-91`）。改法：在 `RHAH_FamineMood` 加 `NotifySiegeFuryStage(Verse.Pawn pawn, int stage)`，comp 里只留一行调用；`SyncThought/ClearThoughts/Remove` 三个（`:71-91`）一起消失，N7 的类也有了正确的家。
- **L3【判断】继承拿错了东西（Refused Bequest）。** `Thought_Memory_RHAH_SiegeFury : Thought_Memory_RHAH_FamineFed`（`:95`），而基类的 `MoodOffset` 与 `VisibleInNeedsTab` 都读 `famineMoodEnabled`（`RHAH_FamineMood.cs:53-58`）【实测】。于是这份 buff 的心情被**另一个**开关二次门控，而本分支专门加的开关是 `famineSiegeFury`（`RHAH_Settings.cs:65`）。【推测】关掉「饥荒心情」后，comp 仍会挂这条记忆（它不看该开关），但心情加成为 0、需求页也不显示。改法：基类改回 `Thought_Memory` 自带 `ShouldDiscard => false`（两行），或按 N7 抽无期限基类并把「随 famineMoodEnabled 归零」显式写进派生类，别靠继承。
- **L4【判断】到场营养不良由两处互相覆盖，靠调用顺序仲裁。** `RHAH_PawnFactory.cs:57-59` 先 `RHAH_FamineArrival.Initialize`（`:20-29` 造／抬到 0.25），紧接着 `RHAH_ArmedDemandEndurance.Apply` 里 `RemoveHediff(malnutrition)`（`:26-27`）把它删掉；两处都没提对方一行，注释只在 `:25` 说「让他们从 0 开始攒」。改法：把「围攻者到场不带营养不良」并进 `RHAH_FamineArrival.Initialize` 的一个显式分支（它已经是到场初始化策略的唯一住所），`Apply` 只负责挂 hediff。
- **L5 合规（放行）**：`RHAH_ArmedDemandEndurance` 放 `Generation/`、由工厂在 `RHAH_FamineWeapons.Apply` 之后调一行，与既有 `RHAH_FamineWeapons.Apply`（`:24-34`）同形；Generation→Pawn 的依赖方向原本就存在（`RHAH_FamineWeapons.cs:3,16` 用 `IsSiege`／`RHAH_Api`）。`Comp*` 落 `Pawn/` 也有先例（`Hediff_RHAH_ClaySatiety`、`Comp_RHAH_Clay`、`RHAH_FamineMood` 都在）。位置本身不算越层。
