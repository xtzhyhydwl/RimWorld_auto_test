## 1. 一句话

给**武装索粮围攻者**（`I-014` 乞食围攻 / `I-030` 强势围攻 / `I-045` 鼠疫强势围攻，三者在 `RHAH_IncidentGroups.cs:21` 同属一组）在**到场时**挂一个 hediff：**按营养不良严重度分三档**给战力与耐痛加成、并挂对应档的心情，**两日后自动消失**；buff 本身可以用设置项 `siegeFuryEnabled` 一次性关掉（关掉后包括心情在内全部回到未改动状态）。

## 2. 机制（最终实现）

- **挂载点**：`RHAH_PawnFactory` 在 `RHAH_FamineWeapons.Apply(pawn)` 之后调 `RHAH_SiegeFury.Apply(pawn)`（`Source/Generation/RHAH_SiegeFury.cs`）。闸门 = `RHAH_ArmedDemand.Enabled && Settings.siegeFuryEnabled` + 有来客快照 + 非玩家阵营 + `RHAH_ArmedDemand.IsSiege(DisplayId)`。
- **到场清空营养不良**：并进 `RHAH_FamineArrival.Initialize` 的显式分支（让围攻者从 0 开始攒），`RHAH_SiegeFury.Apply` 只负责挂 hediff。
- **分档**：`Source/Pawn/HediffComp_RHAH_SiegeFuryStage.cs` 的 `CompPostTick` **每游戏小时**读一次营养不良严重度，把 hediff 自己的 severity 写成 `0.10 / 0.50 / 0.90`（`StageOf` 的档界 = **mal 0.25 / 0.50**），并调 `RHAH_FamineMood.NotifySiegeFuryStage` 换心情。
- **到期**：`HediffCompProperties_Disappears { disappearsAfterTicks: 120000 }`＝两日；**不随开打提前移除**（§7 D1）。
- **不压营养不良**：没有任何上限钳制（§7 D4）。
- **心情**：三条 `Thought_Memory_RHAH_NoExpiry`（不过期），按档互斥替换；挂在 hediff 上 ⇒ 开关关掉时心情也一起没有（用户选的口径：一次性关掉所有新东西）。

## 3. 数值（最终版）

| 项 | 值 |
|---|---|

| hediff severity | `0.10 / 0.50 / 0.90`（由 mal 分档写入，不由时间自然增长） |

| `MeleeHitChance` | `×1.05 / ×1.10 / ×1.20` |
| `MeleeDamageFactor` | `×1.05 / ×1.10 / ×1.20` |
| `MeleeCooldownFactor` | `×0.95 / ×0.90 / ×0.85`（<1 = 更快） |
| `IncomingDamageFactor` | `×0.95 / ×0.90 / ×0.85`（<1 = 减伤） |

**设计意图**：第 1 档就"比原版强一点"；`0.5` 之后即最高档（"开狂暴"）；**不再保护他们**——营养不良按原版走，0.8 意识上限被压、1.0 致死，都是允许的结局。
