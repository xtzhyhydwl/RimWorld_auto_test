## 问题

我在游玩时发现，访客到了该走的时候没有走，原因是他们被困在了房间里。即使这个房间有门，他们也没办法像正常访客或商队那样离开——我必须把门完全敞开，他们才能出去。

## 我认为合理的做法

首先得给他们一条正常的离开路径；在此基础上，如果真的无路可走，再开始凿墙往外走——这一点我也觉得合理，商队就是这么做的。于是我让 agent 去检查问题并做了改动。

## 改动

- 只要他们进入「要离开」的状态，门就不再拦他们，可以正常走出去；
- 如果真的完全没路（房间封死、门被锁），才会凿墙离开，这是最后的办法；
- 顺手删掉了「饥荒来客可以开门」这个设置项：关着会让要走的客人被困住，打开又会让饿着肚子的客人进仓库拿吃的，两头都不合理；
- 已验证：1.6 与 1.7 两个版本都能正常走门离开，门和墙不会受损。

## 说明

改动主要由 AI 起草，但大部分代码经过人工审核与 AI 复审，命名、注释与目录归属也按本仓库的约定整理过，改动的思路写在 commit message 里；具体实现直接看代码即可。
