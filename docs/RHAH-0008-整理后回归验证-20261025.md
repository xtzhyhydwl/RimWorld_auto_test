## 7 【缺原子】/【未验证】

### 7.1 【缺原子】殖民地「库存食物」精确探针

- **想要**：`殖民地库存食物`（仅库存/仅玩家派系）在 `Leaving` 窗口前后各一次可比较读数。
- **现在做不到的原因**：`foodprobe/food_summary` 把**地图上所有**食物算进去（含 `Plant_Grass`/`Plant_TreeOak` 等野生植物），植物会自然生长 ⇒ 对「少吃一口」不敏感（上一轮实测 13785.7 → 13864.1，**升**）；`foodprobe/read_state` 依赖 `FoodControl`，本 profile 未加载。
- **我试过**：本轮**没有**再试 `foodprobe/*`（上一轮已定标为弱判据）；本轮用**存档 XML 逐 def 统计**替代。
- **字段有没有据**：`food_summary` 的 `totalNutrition`/`foodStacks`/`topFoods` 有实测载荷；「仅库存/仅殖民地派系」这个**过滤维度在载荷里不存在**。
- **需要补**：一个只读探针（或 `food_summary` 加 `scope: stockpile|colony`），返回「仅库存区/仅玩家派系」的逐 def 单位数与营养合计。
- **不补也能测的替代（本轮采用）**：存档 XML 逐 def 统计 `MealSurvivalPack/MealSimple/MealFine/Pemmican/MealNutrientPaste/MealLavish`。
- **阻塞等级**：只卡这一条判据的精度，不卡整条需求。
- **可信度**：存档 XML 统计属**强判据**（同一名单逐单位比对）；`food_summary` 属**弱判据**（成立不等于「没吃」）。

### 7.2 【缺原子】受测体饥饿度

- **想要**：该 pawn 的 Food need 当前值（用于确认「他真饿到会触发原版求食」）。
- **做不到**：`rimworld/get_map_target_info` 不带 needs；`ce/*` 面向殖民者；存档 XML 里 `Need_Food` 没写 `<curLevel>`（等于默认值被 Scribe 省略）。
- **需要补**：`rimworld/get_pawn_needs{pawnId}`（或 `get_map_target_info` 增 `needs` 字段）。
- **阻塞等级**：只卡「求食闸门的失效路径是否被真正触发」这一层；不卡「有没有拿食物」本身。

### 7.3 明确未验证的项

1. **凿墙那半未构造**：没有造「无门 / 门被锁」的场景，`canDig=true` 真去砸墙这条路**未验证**；本轮两条时间线都是**走门**离图。
2. **求食路径未强制**：读不到饥饿度（§7.2），没有确认受测体处于 `UrgentlyHungry`，因此「冷却窗口 → 原版 `JobGiver_GetFood` 回退」这条没有被正面跑出来；只证明「83 次采样里没有取食/进食 job + 库存食物一件没少」。
3. **job 观测是采样而非全量**：60/30 tick 采样可能漏掉 <30 tick 的 job；「没有 `Mine`/`Ingest`」的强支撑来自「门/墙 HP 全程不变」与「食物逐单位不变」，不是全量 job 日志。
4. **离场瞬间的截图没取**：本轮只取了 `Refuse` 之前那张；离场位置结论只依赖坐标回读（§4）。
5. **本场景图上有 5 个难民批次**（§3.2）：多来客抢一扇门、幼童/被抱持者、`HostileThreat` 分支**都未测**；受测体在 (247,107) 停留 1620 tick 的原因**未查**（是否与其它难民拥堵有关属推测）。
6. **只测 1 个事件、1 名受测体**；1.6（net48）构建/运行**未验证**。
7. **`Player.log` 未作证据**（全机共用）；本报告全部日志结论只来自 per-profile NDJSON 与桥接内存日志。
8. **Def 反射链路的正面证据是间接的**：能证明的是「Def 里是新类名 + 游戏加载后无 Def 报错 + 存档出现只有新代码才写的 `<canDig>True</canDig>`」，**没有**直接断言「`JobGiver_RHAH_DigOut` 被实例化过」（它只在「走不到边缘」时才会给出凿墙 job，而本轮不需要凿墙）。
