## A 儿童真的会砍人【最高优先，AI 唯一缺的硬证据】

AI 只证明了"儿童拿到和成人一样的 `AssaultColony` duty"，**没抓到它抬手砍人的那一帧**（上一局殖民地在快照前就被打空了）。

**你只要做到一件事：在"刚开打"那一刻存一次档。**

1. 开一局，**殖民者活着**就行（别用会让殖民地速死的玩法）。
2. 开发者模式 → `Actions → Do incident → RHAH_BeggarSiege`。
3. 正常速度让他们走近（游戏内约 1 小时），等**大人开始打人**（能看到挥拳/开枪）时：
4. **F5 存档**，命名 **`r11-manual`**，把路径告诉我（`rhah` profile 下是 `profiles\rhah\Saves\r11-manual.rws`；用你自己那一局就是 `%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Saves\`）。

**我看什么**：那次存档里那批围攻者（带 `RHAH_HungerMark` 的人）逐人的 `role / duty / curJob / targetA`。
**判据**：儿童（年龄 < 13）身上出现 `AttackMelee` / `Goto` 且 `targetA` 是某个殖民者 ⇒ **这条过**。

**你顺手看一眼就行（不用记）**：
- 儿童是不是和大人一起冲进殖民地，而不是留在远处原地转圈？
- 儿童是不是**空手**（没拿枪）？—— 这是设计如此，不是 bug。
- 观感上会不会很怪（9 岁小孩冲上来打人）？

## B 婴儿仍然不参战【回退验证，AI 只有代码证据】

改动写的是 `DevelopmentalStage != Baby`，逻辑上婴儿被排除，但**没有真机样本**（这批围攻 5 人里没婴儿）。

**做法（任选其一）**：
- 触发一个**带婴儿**的来客批次（乞讨/难民那类），把它弄成敌对并进攻；或
- 用开发者模式给某个来客改成婴儿（角色编辑器 / 改年龄），再触发围攻。

**关键**：**存档给我**。**判据**：该婴儿 `duty` 不是 `AssaultColony`，`curJob` 不是攻击；而且**位置留在后面**。
如果婴儿也冲上来打人 ⇒ 这条**回归了**，必须回来找我。
