### E1 乞讨队伍（`RHAH_IncidentGroups.groups[0]`，`Resolve("I-001","I-005","I-042")`）

- **事件 ID / defName**：I-001 `RHAH_LargeRefugeeWave`（Original，大队伍）、I-005 `RHAH_BeggarGroup`（Original，普通乞讨队）、I-042 `RHAH_PlagueBeggarGroup`（Sequel，鼠疫版，复用 I-005 的行为与人数公式，只是 `Category=Plague`）。三者同属一个类槽位：同开关、同权重、同到达态度池（Negative），抽取时三选一。
- **Def 位置**：`1.7/Defs/IncidentDefs/RHAH_M1.xml:3`（I-001）、`:7`（I-005）；`1.7/Defs/IncidentDefs/RHAH_M2.xml:30`（I-042）。`1.6/` 同名文件行号相同（两个文件与 1.7 逐字节相同，已用 `Get-FileHash` 对比为 `True`）。三条 def 的 `workerClass` 分别是 `IncidentWorker_LargeRefugeeWave` / `IncidentWorker_BeggarGroup` / `IncidentWorker_Sequel`，`baseChance` 全为 0。
- **数据位置**：目录 `Source/Incidents/RHAH_IncidentCatalog.cs:88`（I-001，Beggar，Negative，`debugPoints=700`）、`:92`（I-005，300）、`:129`（I-042，300）；组 `RHAH_IncidentGroups.cs:10`；人数/权重 `Source/Incidents/RHAH_IncidentWeight.cs:128`（I-001）、`:132-133`（I-005/I-042 共用 `Spread`）、`:255`、`:258-263`（`Minimum`）。本类不建立亲子关系（`LinkFamily` 只处理 I-003/I-004）。
- **触发条件与权重**：
  - 只在地图家园触发（`Target=Map`；`RHAH_IncidentWeight.cs:420-428`）。正/负池：本类三条都是 **Negative** 池（`RHAH_IncidentCatalog.cs:88,92,129`），受信任影响。
  - 权重 = `FamilyBase(Beggar)=1.0`（`RHAH_IncidentWeight.cs:358`）× 春/冬 `season=1.1`（`:382-385`）× 鼠疫 `0.5`（仅 I-042，`:387-390`）× `TrustFactor = 1 - trust/400`（trust 夹在 ±100，故 0.75–1.25；`:405-418`）× 玩家权重/100（`:1281-1292`）。
  - 类槽位份额 = 三场景权重之和 ÷ 3（`RHAH_IncidentSchedule.cs:260`，即**多场景不放大该类份额**），再在类内按场景权重二段抽（`:209-226`）。
