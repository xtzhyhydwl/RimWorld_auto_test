# 通用管线（7 个事件共用，后文不再重复展开）

这 7 个事件都不是原版讲述者抽的：`baseChance` 全 0，靠自建调度。

1. **调度挂点**：`Source/Incidents/RHAH_IncidentSchedule.cs:416-437` —— Harmony Postfix 挂 `Storyteller.StorytellerTick`，只在 `TickManager.TicksGame % Storyteller.CheckInterval == 0` 时跑。
2. **节奏**：`RHAH_IncidentSchedule.cs:92-139`，正/负池各自一条 MTB（默认 `positiveIncidentDays = negativeIncidentDays = 15`，`Source/Core/RHAH_Settings.cs:12-13`），结算日 1 天宽限（`RHAH_IncidentSchedule.cs:94`）。节奏公式默认 `averageDays`（`Source/Incidents/RHAH_IncidentPace.cs:28`）。
3. **权重**：`RHAH_IncidentSchedule.cs:233-293`。组权重 = 组内「目标匹配」的场景权重**平均**（不是求和，`:259-260` 有注释说明）；单场景权重 = 家族基值 × 季节 1.1（春/冬）× 鼠疫 0.5（Plague）× 信任系数（仅 Negative 池，`1 - trust/400`，trust 夹 ±100）× 玩家权重/100 × 启用开关（`Source/Incidents/RHAH_IncidentWeight.cs:369-418, 75-83`）。
4. **入队**：`RHAH_IncidentSchedule.cs:163-167` → `GameComponent.QueueIncident` → `Source/Core/GameComponent_RHAH_Game.cs:352-365`。队列是三张平行 List（`pendingIncidentDisplayIds/Points/TargetIds`），**会存档**（`GameComponent_RHAH_Game.cs:431-437`）。
5. **出队**：`GameComponent_RHAH_Game.cs:93-160`。**Map 目标**先试 `RHAH_Approach.TrySend`（`Source/Incidents/RHAH_Approach.cs:28-71`）：在世界图上放一个 `RHAH_Approach` 世界物体 + 一封中性信，物体走到家图边缘才真正落地（`GameComponent_RHAH_Game.cs:162-229 SpawnArrived`）。Caravan 目标不走 approach，直接执行（`GameComponent_RHAH_Game.cs:136`）。
6. **执行**：`IncidentDef.Worker.TryExecute`（`GameComponent_RHAH_Game.cs:259`）。
7. **落地**：`RHAH_IncidentFacts.Submit`（`Source/Incidents/RHAH_IncidentFacts.cs:12-119`）：造人 `Source/Generation/RHAH_PawnFactory.cs:13-90` → 访客 Lord（`:75`）→ 记叙事日志（`:104`）→ 开选择信 `:111` 或发到达信 `:113` → `EventMgr.RHAH_EventChainEntry.NoteStarted`（`:115`）。
8. **通用短后续（捕食者）**：`NoteStarted`（`Source/EventMgr/RHAH_EventChainEntry.cs:12-...`）为每个事件起一条 ODF 链，stage 0 立刻执行 `roll_predator`（`Source/EventMgr/RHAH_EventFollow.oxy:4-6` → `Source/EventMgr/RHAH_EventChainProvider.cs:145-148` → `Source/EventMgr/RHAH_EventFollowRuntime.cs:15-59`）。默认 10%（`Source/Core/RHAH_Settings.cs:221 = followPredatorPercent`），命中则把本批来客记为猎物，`ArrivalDelayTicks = 120` tick 后捕食者进场（`Source/Incidents/RHAH_PredationRules.cs:33`）。**这条对本文 7 个事件全部适用**，不属于任何事件的 `switch(displayId)` 专属后续。【实测】
