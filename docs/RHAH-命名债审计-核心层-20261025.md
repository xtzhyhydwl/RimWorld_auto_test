## 层级错位

- **`Core/` 不是底座**：实测 Core 反向引用 `Incidents`/`Pawn`/`Trade`/`Storyteller`/`EventMgr`/`Narrative`/`Generation`/`Caravan`（`RHAH_Settings.cs` 引 4 个域，`GameComponent_RHAH_Game.cs` 引 5 个）。放错的具体表现：`RHAH_Scheduler` 在 Core 做事件触发决策；`RHAH_MapResolver.cs` 在 Core 放事件目标三态解析；`RHAH_Settings.IncidentGroupId/IsIncidentEnabled`（:1222–1254）在设置里做互斥组规则。
- **`Api/` 干净**：实测无任何 `HungerAndHavoc.<实现层>` 引用，符合 `Api/AGENTS.md`。唯一错位是 `Identity/RHAH_ApiHost` 反向做 Data 目录查询与释放策略（见清单）。
- **`Data/` 干净**：实测三个文件只 `using System*`，不碰 Verse/设置/当前游戏，符合 `Data/AGENTS.md`。没有发现行为混入。
- **`Identity/` 放了病害领域**：`RHAH_Plague.cs` + `RHAH_PlagueRuntime.cs`（两者合计 58 次命中/14 文件）装的是鼠疫规则（感染、传播概率、受血判定、按地图 tick），不是身份；调用方是 `GameComponent_RHAH_Game.TickPlague` 与 `MapComponent_RHAH_Map.TickPlague`。建议移到已有的 `Incidents/`（不新开目录）。
- **`Pawn/Compat/` 放了非适配逻辑**：`RHAH_ChildMovement`（15/9）主要读原版生命阶段与 `hediffSet`，只有 `LiftsAgeImmobility` 里的一句 `ModsConfig.IsActive("cyanobot.toddlers")` 属适配；按 `Compat/AGENTS.md`“第三方适配留在此处”，它应回 `Pawn/`。
- **`Core/RHAH_Settings` 承担求值**：`AllowsRequest:1481`（选项种类→开关的策略映射）、`WeightFactors:1533`（事件权重因子装配）、`IsIncidentEnabled`（互斥组）都属行为求值，与 `Core/AGENTS.md`“设置保存用户输入，具体求值留对应领域”不符。
