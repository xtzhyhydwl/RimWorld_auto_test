## 0. 结论（能不能准备 / 缺什么）

**能准备，依赖本机全部齐全；只差「新建 profile + 写一份 ModsConfig.xml」这一步**（按硬约束我没有替你写）。

三件需要你先知道的事实：

1. **少算了一个依赖：`erdelf.HumanoidAlienRaces`（HAR）。**
   RHAH 的 5 个直接依赖里，`Solaris.RatkinRaceMod` 自己的 `About.xml` 里写着
   `<modDependencies>` 含 `erdelf.HumanoidAlienRaces` **【实测 工坊 1578693166/About/About.xml:40】**。
   不装 HAR，鼠族本体加载就会报缺前置。本机工坊已有（839005762），**不用下载**。
2. **RHAH 点名的鼠族本体版本和本机装的不是同一个工坊条目。**
   RHAH 的 `About.xml` 里 `Solaris.RatkinRaceMod` 的 `steamWorkshopUrl` 指向 **3497673755（NewRatkinPlus[1.6]）**，
   而 `Test-Path ...\294100\3497673755` = **False【实测】**；本机有的是 **1578693166（NewRatkinPlus，声明 1.5/1.6/1.7）【实测】**。
   两者 `packageId` 相同，用 1578693166 是**唯一可选项**，但「它与 3497673755 的 1.6 内容是否等价」**未验证**（见风险 ③）。
3. **自动化还需要 `brrainz.rimbridgeserver`**（桥接本体的 mod）。它已在 `游戏\Mods\RimBridgeServer`**【实测】**，
   但只要不进 `activeMods`，CLI 就连不上游戏 ⇒ 必须算进清单。

其余：RHAH / IrisMenus / Oxygendsl 的工坊版与仓库 monorepo 版**版本号一致**（1.1.4 / 1.1.2 / 0.0.1）**【实测】**，
建议一律用**工坊版**，仓库副本只当源码（理由见 §3.3）。

## 1. 自动化环境要点（全部读自代码与文档）

### 1.1 profile 是什么【实测：`src/launcher.js`、`profiles/`】

- **profile = 一个目录** `E:\2026.7以后的新工程\DSH\RimWorld_auto_test\profiles\<名字>\`，**没有注册表、没有配置文件声明 profile**；
  `launcher.js:40-42` 的 `profileDir()` 就是 `path.join(WS,'profiles',profile)`。目录存在即 profile 存在。
- **存档隔离机制**：启动时传 `-savedatafolder=<profiles\<名字>>`（`launcher.js:402`），
  Config / Saves / Screenshots / Prefs **全部**重定向进这个目录 ⇒ 与玩家主力档（`%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\`）物理不相干。
  本轮实测该主力档存在，`Saves\` 下有 **190 个 .rws**，最新 `Autosave-1.rws` 写于 **2026-10-24 16:10:51**。
- **窗口/画面/音量**：`profiles\<名字>\prefs.json`（`launcher.js:371` → `src/prefs.js:159`）。
  键 `monitor` / `screenWidth` / `screenHeight` / `fullscreen` / `devMode` / `langFolderName` 等都从这里来；
  `src/prefs.js:25-34` 的 `FORCE_ALWAYS_PREFS`（窗口化 1600x900、`runInBackground`、`pauseOnError:false`）**每次启动强制**。
- **现有 profile（实测目录）**：`vanilla`（**561 项 activeMods**，是全量档，不是纯净基线！）、`voiced`（6 项）、`bike`（14 项，鼠族先例）、`dropbisect-selftest`、`steam-attach-20261004`。

### 1.2 mod 列表怎么指定【实测】

- **写 packageId，不写路径**。`profiles\<名字>\Config\ModsConfig.xml` 的 `<activeMods><li>…</li></activeMods>`，
  每项是 packageId（例：`profiles\bike\Config\ModsConfig.xml` 里的 `brrainz.harmony` / `erdelf.HumanoidAlienRaces` / `Solaris.RatkinRaceMod`）。
  同一文件还有 `<version>` 与 `<knownExpansions>`（6 个 DLC）。
- **本项目从不自动写它**：`src/` 里没有任何写 ModsConfig 的代码（`自动化测试\STATUS.md:49` 明确写了这条），
  `launcher.js` 启动前只 `mkdir` 出 `Config\`、`Saves\` 并写 `Prefs.xml`（`launcher.js:360-372`），**不碰 ModsConfig**。
- ⚠ **文档里被反复引用的 `node scripts/modsconfig.mjs {list|add|remove|set|baseline|copy-main|preset}` 在本机不存在**：
  `scripts\` 目录**是空的**（`Get-ChildItem scripts -Force -Recurse` 计数 = 0），且 `git ls-files scripts` = **0 个文件**（从未被跟踪）。
  引用它的地方：skill `rimworld-auto-test`、`README.md`、`docs\验证结果总报告.md:112`、`docs\交接-自动化测试.md`、
  `共享单车\STATUS.md:59`、`docs\CHARACTER-EDITOR-可编程驱动调研.md:645`。
  ⇒ **【建议】手写 ModsConfig.xml，不要指望这条命令**（本文 §4.1 给了完整内容）。

### 1.3 CLI 命令【实测：`src/cli.js:368-385` 的 help 文本】


- 默认 profile 是 `vanilla`（`cli.js:128`）——**这条很危险，见风险 ⑥**。
- 端口：不传 `--port` 就在 **5174..5183** 里挑第一个空闲的（`launcher.js:291-300`），端口来源写进记录。
- `start` 会先校验「同 profile 是否已在跑」（`launcher.js:344-350`），机器上别的 RimWorld **只警告不拦**（`launcher.js:353-357`）。
- `stop` 默认只杀**本 profile 记录里的 PID**；`--force` 才是全机强杀（`launcher.js:549-605`）。
- `--doorstop` 不传 ⇒ 自动加 `--doorstop-enabled false`（`cli.js:141` + `launcher.js:419`），这是桥接能起来的必要条件（README 坑 1）。

### 1.5 mod 怎么"装进"游戏【实测】

- 游戏**只**从两处加载 mod：`游戏安装目录\Mods\` 和 `...\steamapps\workshop\content\294100\`。
  **不扫描 profile 目录、不扫描 monorepo**（skill §5 原话；本轮用 `Mods\` 下的 junction 实测印证）。
- 本仓库让自己开发的 mod 被看见的方式是**目录联接（junction）**，实测 `游戏\Mods\` 下 6 个：
  `BikeProbe`、`ColonyRecorder`、`DSH_GameLink`、`FoodControl`、`副官语音` → 指向 `<WS>\mods\…` / `<WS>\语音副官`；
  `DSH_AutoTest` → `<WS>\profiles\vanilla\Mods\DSH_AutoTest`。
- **没有任何 CLI 命令负责"把 mod 复制进游戏"**；junction 是手工/一次性建的（`launcher.js` 里无相关代码）。
- ⇒ 对 RHAH 这套：**不需要动游戏目录**，工坊里的 5 个 mod 本来就能被看见，只需要在 profile 的 ModsConfig 里列出来。

### 4.2 「起这个 profile」的一条命令

```powershell
cd 'E:\2026.7以后的新工程\DSH\RimWorld_auto_test'
node src/cli.js start --profile rhah --width 1600 --height 900 --monitor 2
```

- `--profile rhah`：新 profile 名（`profiles\` 下目前没有同名目录）【实测】。
- `--monitor 2` + 1600x900：把窗口放副屏、小窗口，减少抢焦点/抢 GPU（`voiced` profile 已验证过这套值；**先确认副屏是 1080p**，否则窗口会溢到主屏——skill §「多显示器」）。
- 不传 `--doorstop` ⇒ 自动 `--doorstop-enabled false`（桥接必需）。

### 4.3 怎么「只生成一个新存档、不碰现有存档」
