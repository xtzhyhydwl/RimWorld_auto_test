## 一、首先：这次验收**是否有证明力**？—— 有

之前几次跑不成，是因为**削存粮的手段打不到食物上**（`forbid_some` 改了 8 个物品，
但 `forbiddenFoodNutrition` 仍是 0）。这次修好了（新增 `forbid_food`，只动食物物品）：

```
可用营养 51.3 → 6.3（5 堆）        ← 真的削下来了
```

而且粮食数据**全程在下降**（51.3 → 45 → 36 → 27 → 19.8 → 38），
种植区**从 0 一路涨到 561 格**，说明 mod 真的在自主种地，不是靠开局存粮混过去。

→ **这次验收是有效的。**

## 三、失败的 3 条 —— 以及**根因**

| # | 判据 | 实测 |
| --- | --- | --- |
| ① | 没人死 | ❌ 3 人 → 1 人 |
| ③ | 心情不触底（mood > 0.15） | ❌ 最低 **0.012** |

### 死因（从游戏信件里查到的，不是猜的）

```
tick=91300   (+1.5天)  Chaz has been **torn to death**        ← 被野兽撕碎
tick=223656  (+3.5天)  Lego    died. Cause: **Blood loss**    ← 失血
tick=225999  (+3.5天)  Whistler died. Cause: **Blood loss**   ← 失血
最近还有：Raid: Pill Gang（wasters 来袭，tick=324000）
```

**全部是敌对生物/袭击造成的战斗伤亡。**

### 关键结论：**不是饿死的，也不是 mod 的自动化出错**

- 粮食全程充足（最低 19.8）
- 种植区一路扩大
- 死因是**失血**（战斗），不是营养不良

→ 也就是说：**mod 做到了"食物闭环"，但殖民地死于它管不到的事情。**

## 四、这次失败暴露的真实缺口（不是调参能解决的）

| 缺口 | 说明 |
| --- | --- |
| **没有威胁响应** | 野兽/袭击来了，小人不会躲进屋里、不会集结、不会撤退。mod 完全不管战斗 |
| **没有安全屋** | 我们盖的房子**没有防御价值**（就是四面墙 + 门，没有"关上门躲起来"的行为） |
| **心情只被观测，没被干预** | mood 掉到 0.012 时，mod 什么都不做（没有娱乐/舒适度/美观的干预） |

★ 后两条正好接上用户之前的两个提示：
1. 用户说过「房子建出来，之后的发展都不考虑」—— 现在"之后的发展"就是**防御**
2. 用户提过**地板与心情管理挂钩**（卧室铺地板提升美观）—— 心情干预确实是缺口

## 五、按用户的要求：**不调参凑数**

用户明确指示过：
> 「如果 5 天验收失败，**不要调参数强行通过**，要诚实下结论并把它变成下一步需求。」

所以这次**不改任何参数**去让判据变绿。结论是：

> **FoodControl 现在能保证"有饭吃"，但保证不了"活着"。**
> 差距在**威胁响应**，而那是一个新的、独立的领域（不该塞进食物的域里）。

## 六、下一步（按优先级）

1. **威胁响应域**（新）—— 最低限度：敌意目标出现时**让小人躲进最近的封闭空间**并关门。
   这一条就能大幅提高存活率，而且技术上我们已经有"封闭空间"的数据（住处域建的房子）。
2. **心情干预** —— mood < 阈值时做点什么（卧室铺地板、加娱乐设施）。
3. 重跑 S5 作为回归（这次要**同时**看"有饭吃"和"活着"）。
