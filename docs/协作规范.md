# 协作规范

**给主会话的规则。** 目的是让长项目在换会话后依然顺滑，不被上下文膨胀拖笨。

实测背景（本仓库第一个会话的数据）：跑到 50.8 万 token 时，
上下文的 **70.5% 是助手自己写的话**、24.8% 是工具输出、你（用户）只占 **0.2%**。
所以膨胀的主因不是"用户话说多了"，也不是"工具输出太多"，而是**助手每轮都在写长篇总结**。

---

## 一、核心原则：对话不是状态存储

对话历史有三个致命缺陷：**不能检索、不能 diff、换会话就丢**。
而磁盘上的文件没有这些缺陷。

所以：

> **能写进文件的，绝不留在对话里。**

每条重要结论产生时，**立刻**写进对应文件。不要指望"后面总结"——
后面可能没有后面，会话可能就断了。

---

## 二、主会话保持"浅"

主会话只做四件事：

| 做 | 不做 |
| --- | --- |
| 做决策、定接口 | 写大段代码 |
| 审阅子代理的产出 | 逐行读别人的源码 |
| 派活、整合 | 读大段 JSON / 日志 / 报告 |
| 更新状态文件 | 复述已知内容 |

**回复尽量短。** 需要展示细节时，写文件 + 给路径 + 两三句说明。

自检：如果我的回复超过约 1500 字，先问自己"这些能不能进文件"。

---

## 三、什么进文件、什么进对话

| 内容 | 去处 |
| --- | --- |
| 通用经验、可复用流程 | **skill**（`~/.dsh/skills/` 全局，或仓库 `.dsh/skills/` 项目级） |
| 环境事实、机制说明 | `docs/` 下的专题文档 |
| 架构决策、接口设计 | `docs/<项目名>-设计.md` |
| 进度、待办、已知问题 | `STATUS.md`（仓库根） |
| 测试产物、报告、截图 | `runs/<runId>/`（已在 .gitignore） |
| 调研结果 | `docs/<主题>-调研.md` |
| 代码 | 正常写进源码目录 |

**对话里只留**：决策、结论、下一步、以及"文件路径 + 一句话说的什么"。

---

## 四、子代理怎么派

子代理的价值：**它的中间步骤不进主上下文**。但它的**返回值会进**，所以：

> **要求子代理把成果写进文件，只回报「路径 + ≤200 字摘要」。**

派活模板：

```
任务：<一句话目标>

背景（必须自包含，子代理看不到我们的对话）：
- 仓库位置：<绝对路径>
- 先读：<具体文件>
- 约束：<技术约束>

产出要求：
1. 把详细内容写进 <具体文件路径>
2. 回报给我：文件路径 + 不超过 200 字的摘要 + 你验证了什么、没验证什么
```

**要点**：
- 子代理**不共享上下文**，提示词必须自包含（宁可多写背景）
- 明确要求"**区分实测和推测**"，否则它会编
- 让它**写文件**，不要在返回值里堆内容
- 用 `subagent`（全新上下文）而不是 `subagent_fork`（继承对话，等于没省）

---

## 五、状态文件：STATUS.md

仓库根维护一个 `STATUS.md`，主会话每完成一个阶段就更新。

至少包含：

```markdown
# 状态

## 当前在做什么
<一两句>

## 已完成
- [x] ...

## 待办
- [ ] ...

## 已知问题 / 坑
- ...

## 最近一次验证
<什么时候、跑了什么、结果>
```

新会话读它就能接手，不用翻对话历史。

---

## 六、会话轮换

**什么时候换**：
- 上下文占用超过约 40%（用 `node scripts/analyze-session3.mjs` 查）
- 一个阶段结束、要开新阶段
- 感觉"开始重复问同样的东西"

**换之前必须做**：
1. 把结论写进 `docs/` 或 skill
2. 更新 `STATUS.md`
3. `git commit`
4. 确认游戏/环境状态（是否还在跑）

**新会话开局**：读 skill（自动）+ `docs/协作规范.md` + `STATUS.md` + `docs/mod开发基础.md`。

---

## 七、硬规则清单

1. 回复尽量短；超过 1500 字先想能不能进文件
2. 重要结论**当场**写文件，不要留到最后
3. 子代理一律「写文件 + 回报路径 + ≤200 字」
4. 子代理提示词必须自包含
5. 要求子代理区分「实测」和「推测」
6. 每阶段更新 `STATUS.md`
7. 阶段结束就 commit
8. 不把大段 JSON / 日志 / 报告贴进对话
9. 不让子代理用 `subagent_fork` 来"省事"（省不了）
10. 换会话前先把状态落盘
