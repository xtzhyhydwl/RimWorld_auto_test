# 测试 SOP 目录

> 本目录 = 一次测试的**阶段序列**（先做什么、每步什么时候算完成）。
> skill `rimworld-auto-test-closed-loop` 只管"怎么想、什么时候停手"，阶段细节在这里，skill 里只有指向本目录的指针。
> 生长方式：**加一个文件 + 加一行登记**。skill 不动。

## 怎么选

1. 先看[标准六阶段](标准-六阶段.md)——覆盖大多数：起实例 → 进图 → 摆场景 → 推时间 → 等判据 → 取证。
2. 再看下面「特殊流程」表，按**适用条件**挑一条。
3. 都不匹配 ⇒ 自建一条（见末节），跑通后登记。

**任何一条 SOP 开跑前，先过一遍[环境自检](环境自检.md)的四项检查**（桥接归属 / 必备 mod / 加载顺序 / 摆小人的工具）。

## 自建与登记

1. 照下面的骨架新建 `<类型>-<名字>.md`（例：`多实例对撞.md`、`存档读档.md`、`长时推进.md`）。
2. 在「特殊流程」表加一行：**一句话适用条件 + 文件名**。适用条件写"什么需求该用它"，不写"它做了什么"。
3. 跑通一次后再登记为可用；没跑通的标【未验证】。

## SOP 骨架

```
# <SOP 名字>
## 0 什么时候用：适用条件 / 不适用时去哪
## 1..N 阶段：每阶段 = 动作 + 完成判据 + 证据落哪
## 失败怎么读：指向 ../失败判读.md 的具体一节
## 收工：停实例、清理残留
```

没有完成判据的阶段不算阶段；判据不过不进入下一阶段。

失败（动作返错、等待超时、探针挂住、断言不成立）统一在[失败判读](失败判读.md)里找处置，不写回 SOP。
