# 环境自检（每次开测前跑，不过就停手）

> 目的：确认这套环境**能摆条件、能读状态、能推时间**。缺一件，后面测出来的结论都不可信。
> 判据全部是可回读的字段或文件，不靠"看起来没问题"。

## 0 检查项

**硬性（不过就停手）**

| # | 检查 | 判据 | 不过怎么办 |
| --- | --- | --- | --- |
| 1 | 桥接与归属 | `status --profile <p>` 的 `bridgeResolution.ok = true` | 重启实例，等 `bridge-ready` |
| 2 | 底座 mod 已加载 | `list_mods`：Core / Harmony / RimBridgeServer / 被测 mod 都 `loadedInSession = true` 且 `unsatisfiedDependencies` 为空 | 停手报；按 §3 补 |
| 3 | 加载顺序健康 | `get_mod_configuration_status` 无 ordering issue、`restartRequired = false` | 按提示调序；调完必须重启实例 |

**按需（这次测试用到才必须；缺了同样停手，不降级）**

| # | 这次要用 | 必须有什么 | 判据 |
| --- | --- | --- | --- |
| 4 | `live --until` / `wait --source event` | `dsh.gamelink` 在 profile 里 | `runs/live/<p>.ndjson` 在写 |
| 5 | 摆/读小人状态 | `void.charactereditor` 在 profile 里 | `list_mods` 里它 `loadedInSession = true` |
| 6 | `ce/*` 反射工具 | 游戏侧 `BridgeTools\DSH.CEBridge\` 有 DLL | `call ce/probe` 有返回 |

```powershell
node src/cli.js status --profile <p>
node src/cli.js call rimworld/list_mods                 # 看 enabled / loadedInSession / unsatisfiedDependencies
node src/cli.js call rimworld/get_mod_configuration_status
node src/cli.js call ce/probe
node src/cli.js tools ce                                # 有没有 ce/* 工具
```

`list_mods` 的判法是看**每个必备项都 `loadedInSession = true` 且 `unsatisfiedDependencies` 为空**，而不是只查 packageId 在不在清单里。

## 1 mod 清单

| packageId | 类型 | 为什么 | 缺了会怎样 |
| --- | --- | --- | --- |
| `ludeon.rimworld` | 硬性 | Core | — |

## 3 缺 mod 怎么补

1. 确认 mod 已在游戏侧：工坊 `294100/1874644848` 是 CE 本体；或 `游戏目录\Mods\`。
2. 在 `profiles\<p>\Config\ModsConfig.xml` 的 `activeMods` 里加 packageId（Harmony 在 Core 之前，其余排在后面；CE 依赖 Harmony）。
3. `stop --profile <p>` → `start --profile <p>`，再跑 §0 第 2、3 项复核。

不动用户正在玩的那一局；不为了补 mod 用 `--force`。

## 4 缺 CE 桥接（`ce/*` 工具不存在）

`node src/cli.js tools ce` 没有任何 `ce/*` ⇒ 反射路线没部署。**2026-10-24 文件检查：游戏侧 `BridgeTools\DSH.CEBridge\` 是空的**，仓库里 `bridge\DSH.CEBridge\DSH.CEBridge.dll` 在。

部署：把该 DLL 复制到 `<游戏目录>\BridgeTools\DSH.CEBridge\`，重启实例，再跑 `ce/probe`。
CE 升级后 `ce/probe` 失败 ⇒ 反射用的类型/成员字符串对不上，重编（源码 `bridge\DSH.CEBridge\DSH.CEBridge.cs`）。
