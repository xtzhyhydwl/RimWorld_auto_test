# 测试模板：六阶段（复制即用，2026-10-24）

> 用法：**整份复制**到你这次测试的报告里，按顺序填空。填不下去的地方，就是「缺原子」或「需求没说清」——
> 按 `组合skill` 的停手模板报，不要硬编。
> 这个模板给的是**下限**（照着做不会漏步骤）；要更自由的组合，用四层原子自己拼（上限更高）。
> 模板不含业务内容：每一格都要你按当次需求替换。

## 用这个模板时的自检（三秒扫一遍）

- [ ] 每个动作后面都跟着一个判据，**没有一处 `Start-Sleep`**
- [ ] 没有把 `success: true` 当证据
- [ ] 每条断言都能写成「路径 + 算子 + 期望值」
- [ ] 多实例时发命令前看过 `status.bridgeResolution.ok`
- [ ] 证据都落在 `runs/`，报告里只给路径
- [ ] 做不到的部分进了 §8，而不是被"看起来对"糊过去
