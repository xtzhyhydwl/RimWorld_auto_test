# 等待机制：事件驱动（2026-10-17）

**规则一句话**：要等「游戏到了某状态 / 某事件发生」，用 DSH_GameLink 的事件推送（`node src/cli.js live`）挂成后台 job；**不要**用固定秒数的 `Start-Sleep` 去赌。

## `live` 参数表（核实来源：`src/live.js` 的 `USAGE`/`runLive`，`src/cli.js:128,322-331`）

| 参数 | 语义（按代码） |
| --- | --- |
| `--profile <名>` | 默认 `vanilla`（`src/cli.js:128`） |
| `--until '<条件>'` | 等条件成立：命中打印该行原文 **exit 0**；超时 **exit 2**；参数错 **exit 1** |
| `--last N` | 打印文件末尾 N 条并**立即** exit 0，不等待；与 `--until` 同时给 ⇒ exit 1 |
| `--new-only` | 先跳到文件当前末尾，只看新增行；与 `--from-start` 同时给 ⇒ exit 1 |
| `--timeout <ms>` | 默认 **120000**；必须正数 |
| `--source events\|log` | 默认 `events`（NDJSON）；`log` = 跟 `Player.log`，每行当 `{kind:"log", text:<原文>}` |
| `--file <路径>` | 直接指定被跟读的文件 |

条件语法（`parsePredicate` / `matches`）：`key=value` = 顶层字段**按字符串相等**（数字/布尔取 JSON 字面量，`tick=900`/`speed=1`/`opened=true` 都成立）；`key~value` = 顶层字段**包含子串**（**不是正则**）；空格或 `&&` 连接，**全部**成立才命中；值里可以有空格。**默认从文件头扫**（历史里已有 ⇒ 立刻命中）。事件文件查找顺序：`--file` → `$DSH_LIVE_DIR/<profile>.ndjson` → `<存档目录>/dsh-live/game.ndjson`（存在才用）→ `runs/live/<profile>.ndjson`。

## 事件 `kind` 表（核实来源：`mods/DSH_GameLink/Source/GameLinkComponent.cs`、`LogTap.cs`、`LiveChannel.cs`）

| kind | 什么时候发 | 额外字段 | 典型 `--until` |
| --- | --- | --- | --- |
| `game_loaded` | `LoadedGame`/`StartedNewGame` 后第一次 Update | `tick` `map` | `kind=game_loaded` |
| `colony_started` | 首次出现玩家主基地地图（只报一次） | `tick` `colonists` `map` | `kind=colony_started` |
| `window` | 顶层窗口**类型名变化**时（栈尾窗口） | `opened` `type` `forcePause` | `kind=window opened=true` |
| `log` | 含 `[VD]` 的 `Log.Message`/`Log.Warning`；`Log.Error` **全部**转发 | `level` `text` | `kind=log text~[VD] 1 incident` |
| `heartbeat` | 实时每 **3 秒**一条（`HeartbeatIntervalSeconds=3`） | `tick` `programState` `speed`（暂停 0）`map` | `kind=heartbeat speed=1` |
| `error` | mod 自己捕获到异常时 | `where` `message` | `kind=error` |

写盘：`runs/live/<profile>.ndjson`，一行一条、UTF-8 无 BOM、每条 Flush、8 MB 轮转一代（`<file>.1`）。
