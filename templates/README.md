# 建筑样板库（templates/）

这里是**样板房的可读编码**。mod 需要盖房时**直接抄**这里的样板，而不是现场生成 ——
因为"抄一个已知能用的设计"远胜于"现场生成一个可能很蠢的设计"。

设计说明见 [../docs/蓝图模板系统-设计.md](../docs/蓝图模板系统-设计.md)。

## 样板长什么样

一份样板就是一个 JSON，核心是 `rows`（逐格的角色图）和 `roles`（每个角色**允许用什么**）：

```jsonc
{
  "id": "bedroom-13x13",
  "name": "基本卧室 13×13",
  "origin": "user",                  // user = 你在游戏里手造并导出的
  "size": { "w": 13, "h": 13 },
  "tags": ["bedroom", "starter"],
  "rows": [
    "WWWWWWWWWWWWW",                 // W 墙  D 门  B 床  L 光源  . 空地
    "W...........W",
    "..."
  ],
  "roles": {
    "W": { "name": "wall",  "accepts": ["Wall"],                      "isWallLike": true },
    "D": { "name": "door",  "accepts": ["Door"],                      "isDoorLike": true },
    "B": { "name": "bed",   "accepts": ["Bed", "DoubleBed"],          "isFurniture": true },
    "L": { "name": "light", "accepts": ["TorchLamp", "StandingLamp"], "isFurniture": true }
  }
}
```

### 两个关键设计

**1. `rows` 是行字符串，不是二维数组**
13×13 的行字符串在编辑器里**直接就能看出形状**，可以手画、diff 里也能看懂。

**2. `accepts` 决定"这个槽位允许用什么"**
这是「**不必百分百还原，只要物块对得上**」的落点：
床槽写 `["Bed","DoubleBed"]` 就表示两种床都能用；
墙槽写 `["Wall"]` 表示任何 defName 含 `wall` 的墙都行（包括 mod 的墙）。

放样板时按 `accepts` 顺序试：**有库存吗 → 能放吗 → 用第一个通过的**。
全都不行 → **那个槽位留空并记录**（不整个放弃）。

### 代号约定

| 代号 | 角色 | 说明 |
| --- | --- | --- |
| `W` | wall | 墙（含 mod 墙） |
| `D` | door | 门 |
| `B` | bed | 床 |
| `L` | light | 光源（火把/立灯/篝火） |
| `T` | table | 桌子 |
| `S` | seat | 凳子/椅子 |
| `E` | storage | 储物（架子等） |
| `C` | workbench | 工作台/灶台 |
| `A` | furniture | 其他家具（`accepts` 留空待你填） |
| `.` | — | 空地 |

## 怎么把你在游戏里造的样板收进来

### 第 1 步：在游戏里造

开上帝模式，像平常一样造你的样板房（卧室 / 仓库 / 厨房 …）。
**不用管坐标，先造好。**

### 第 2 步：告诉我它在地图上的位置

两种方式（第二种更好，不用记坐标）：

- **报坐标**：你告诉我大概是 `x, z, 宽, 高`（我会用一段稍大的矩形去扫，工具会自动裁到墙的外沿）
- **划一个区圈住它**（推荐）：用游戏自带的划区工具（比如画一个种植区）把样板房圈起来，
  然后告诉我"区已经划好了" —— 我读那个区的包围盒来扫，你不用记任何坐标

### 第 3 步：我扫描并生成样板

我会跑：

```bash
node scripts/template-capture.mjs <样板id> --x .. --z .. --w .. --h ..
```

它会：
1. 扫描那块矩形（只读，不改游戏）
2. **自动裁到墙的外沿**（你框大一点也没关系）
3. 按**角色**分类（墙/门/床/光源/桌椅/工作台…）
4. 生成 `templates/<样板id>.json` 并保存原始扫描到 `runs/template-captures/`
5. 打印形状给你核对

### 第 4 步：检查 `accepts`

工具只能知道**你实际用了什么**，而 `accepts` 决定"还允许用什么替代"。
比如扫描到 `Bed`，默认会写成 `["Bed", "DoubleBed"]`；
如果还允许 mod 的床，你手加进那个数组就行。
