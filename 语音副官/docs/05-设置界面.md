> **这份文档管什么**：设置窗口的四页签与**每一个字段**（字段名 / 控件 / 默认值 / 范围 / 落到哪个 `Settings` 字段 / 谁消费），以及"改一个字段只改一处"的落点表。

## 3. 页签二：语音（`Tab_Voice`）

| 字段名 | 控件 | 默认值 | 范围 | `Settings` 字段 | 谁消费 |
|---|---|---|---|---|---|
| 服务地址 | 单行文本框 | `https://api.siliconflow.cn/v1/audio/speech` | 任意字符串 | `BaseUrl` | `SegmentSynthesizer`（拍 `TtsRequestParams`）+ `SpeechLibrary`（算 `VoiceFingerprint`） |
| API Key | 密码框（`•` 掩码）+ `清空` 按钮 | 空 | 任意字符串 | `ApiKey` | `SegmentSynthesizer`（经快照给 `TtsClient`） |
| 模型 | 单行文本框 | `FunAudioLLM/CosyVoice2-0.5B` | 任意字符串 | `Model` | 同上 + `SpeechLibrary`（`VoiceFingerprint` 的输入） |
| 音色 | 单行文本框 | `FunAudioLLM/CosyVoice2-0.5B:alex` | 任意字符串（必须带模型名前缀） | `Voice` | 同上 + `SpeechLibrary`（`VoiceFingerprint` 的输入） |
| 输出格式（固定项） | **只读文本** | `wav` | 固定 | 无字段（`TtsRequestParams.ResponseFormat` 常量 = `wav`） | `SegmentSynthesizer` / `WavReader` |
| 试听 | 按钮 | — | — | — | 动作：`Announcer.SpeakDirect("副官就位")` |
| 状态条 | 只读一行 | 无失败 ⇒ `已配置`；失败或未配置 ⇒ `TtsClient.LastError` 的文案 | — | 只读 `TtsClient.LastError`（`TtsClient` 在未配置时也写一条 `Message = 未配置`） | `UI/Tab_Voice` |

- **API Key 落盘是明文**：存在 `Config` 下的本 mod 设置 XML 里；行下固定一行小字「明文存在本地 Config，别把 Config 发给别人」+ 掩码显示（只显示末 4 位）【实测】。
- **输出格式锁 `wav`**：没有四选一控件，只有一个只读文本；解码链只实现 WAV（`WavReader`）。
- **试听即连通性检查**：不另做 `/v1/models` 探测。点一次＝一次真实合成；失败时同一行显示 `TtsClient.LastError`（状态码 + 响应体前 200 字），不静默。
- 服务地址默认 `.cn` 域名：`.com` 用国内 key 返回 401【实测：`runs/tts-probe/`】。

## 4. 页签三：音量与节奏（`Tab_Volume`）

| 字段名 | 控件 | 默认值 | 范围 | `Settings` 字段 | 谁消费 |
|---|---|---|---|---|---|
| 总音量 | 滑条（显示百分比） | 100% | 0–200% | `MasterVolume`（0–2 的 float） | `VoicePlayer`（每帧现读） |
| TTS 音量 | 滑条（显示百分比） | 100% | 0–200% | `TtsVolume` | `VoicePlayer`（每帧现读） |
| 语速 | 滑条 0.50–2.00（显示 `1.00×`） | `1.0` | 0.5–2.0 | `Speed` | `SegmentSynthesizer`（进 `TtsRequestParams.Speed`，逐次请求生效） |
| 句间停顿 | 滑条（显示 ms） | 120 ms | 0–500 ms | `GapMs` | `VoicePlayer`（每帧现读，片段之间的 `dspTime` 间隔） |
| 同句最多点名 | 滑条（显示人数） | 2 人 | 0–8 人 | `MaxNamedInBatch` | `SegmentPlanner`（点名截断，0 = 只报数） |
| 队列上限 | 滑条（显示句数） | 6 句 | 1–20 句 | `QueueLimit` | `SpeechQueue`（超限丢弃规则） |
| 威胁可打断 | 复选框 + 说明行 | 开 | 开/关 | `ThreatInterrupts` | `SpeechQueue`（插到队首） |

- 音量走自建 `AudioSource.volume`，不进原版混音组；两个音量分开是因为 TTS 音频通常比其它音源响。
- `GapMs` 是**片段之间**的停顿，不是句子之间；句子之间由队列节拍决定。
- 聚合的合并边界固定为"同 tick"，不进本页（`03` §5）。

|---|---|---|---|---|---|
| 路径日志 | 复选框 + 说明行 | 关 | 开/关 | `TraceEnabled` | `Trace.Step`（唯一） |
| 缓存占用 | 只读文本（`LibraryUsage.Describe()`） | — | — | 读 `SpeechLibrary.Usage` | `UI/Tab_Debug` |
| 清缓存 | 按钮 | — | — | — | 动作：`LibraryJanitor.ClearAll()`（删文件 + 清索引 + 落索引） |
| 库上限 | 滑条（显示条数） | 3000 条 | 0–20000 条 | `LibraryLimit` | `LibraryJanitor`（`CheckLimit` 与每轮第 ③ 步同一函数） |
| 清理周期 | 滑条（显示秒） | 300 s | 30–3600 s | `JanitorIntervalSeconds` | `DeputyGameComponent`（计时） |
| 预热节流 | 滑条（显示条/分钟） | 100000 条/分 | 1–1000000 条/分 | `WarmupJobsPerMinute` | `WarmupScheduler` |
| 数字转中文 | 复选框 + 说明行 | 关 | 开/关 | `NumericText` | `SegmentPlanner`（`Number` 段是否经 `NumericText` 纯函数转中文，见 `03` §4.4） |

| 手动朗读 | 文本框 + `朗读` 按钮 | 空 | 任意文本 | 无字段（不落盘） | 动作：`Announcer.SpeakDirect(文本框内容)` |

- **最近播报**每行五列：时间 / 类别 / 原文 / 是否整句命中（`FromSentenceCache`）/ 用时 ms。
- **缓存占用**是"这个 mod 额外花了多少磁盘"的唯一可见处，必须显示成 `1,234 条 / 12.3 MB` 这种可读形态。
- **清缓存**必须同时清磁盘与索引（只清内存等于没清）。
- **手动朗读**绕过事件与开关，直接把文本送 `SegmentPlanner.PlanRaw` → 合成 → 播放，用于调音色。

| `Settings` 字段 | 存盘键 | 类型 | 备注 |
|---|---|---|---|
| 22 个类别开关（经 `IsCategoryEnabled` / `SetCategoryEnabled` 读写） | `enabled_<类别名>` | `bool` | 遍历 `SpeechCatalog.Entries` 逐条写，键名由类别名拼 |
| `BaseUrl` | `baseUrl` | `string` | 空串会触发 `TtsClient` 的配置闸 |
| `ApiKey` | `apiKey` | `string` | 明文落 `Config` |
| `Model` | `model` | `string` | 参与 `VoiceFingerprint` |
| `Voice` | `voice` | `string` | 必须带模型名前缀 |
| `Speed` | `speed` | `float` | 下发给 TTS |
| `MasterVolume` | `masterVolume` | `float` | 0–2 |
| `TtsVolume` | `ttsVolume` | `float` | 0–2 |
| `GapMs` | `gapMs` | `int` | 片段间停顿 |
| `MaxNamedInBatch` | `maxNamedInBatch` | `int` | 点名上限 |
| `NumericText` | `numericText` | `bool` | 数字转中文；**待加字段** |
| `QueueLimit` | `queueLimit` | `int` | 队列上限 |
| `ThreatInterrupts` | `threatInterrupts` | `bool` | 威胁插队 |
| `LibraryLimit` | `libraryLimit` | `int` | 条数上限 |
| `JanitorIntervalSeconds` | `janitorIntervalSeconds` | `int` | 清理周期；**待加字段**（现有代码里还没有） |
| `WarmupJobsPerMinute` | `warmupJobsPerMinute` | `int` | 预热节流；**待加字段**（现有代码里还没有） |
| `TraceEnabled` | `traceEnabled` | `bool` | 路径日志 |

- `Scribe_Values.Look` 以**当前值**作缺省值：构造期已写好默认值，因此老配置缺键时读回的就是代码默认值，不会读成 `0`/`false`【实测】。

**本版删除的三个字段（字段、控件、存盘键一并移除）**

| 字段 | 原控件 | 删除理由（一句事实） | 现状 |
|---|---|---|---|
| `ResponseFormat` | 输出格式四选一（wav / mp3 / opus / pcm） | 解码链只有 `WavReader`（只认 WAV） | 常量 `TtsRequestParams.ResponseFormat = "wav"`；语音页只显示只读文本 `wav` |
| `BatchWindowMs` | 「合并窗口」滑条（0–5000 ms） | 聚合边界固定为"同 tick"（`03` §5.1） | 无字段、无控件；节奏页不再有这一行 |
| `SpeechStyle` | 「说话风格」三选（副官 / 中性 / 简省） | 中文文案只有一套模板（`SpeechCatalog.Phrases`） | 无字段、无控件；语音页不再有这一行 |

### 6.1 可调项清单（16 个字段 + 22 个类别开关）

| 组 | 字段 | 读者数 | 唯一读者 |
|---|---|---|---|
| 类别开关 | 22 个（经 `IsCategoryEnabled` / `SetCategoryEnabled`） | 1 | `Switchboard` |
| TTS | `BaseUrl` / `Model` / `Voice` | 2 | `SegmentSynthesizer`（快照）+ `SpeechLibrary`（`VoiceFingerprint`） |
| TTS | `ApiKey` / `Speed` | 1 | `SegmentSynthesizer`（快照） |
| 播放 | `MasterVolume` / `TtsVolume` / `GapMs` | 1 | `VoicePlayer` |
| 组句 | `MaxNamedInBatch` / `NumericText` | 1 | `SegmentPlanner` |
| 队列 | `QueueLimit` / `ThreatInterrupts` | 1 | `SpeechQueue` |
| 库 | `LibraryLimit` | 1 | `LibraryJanitor` |
| 库 | `JanitorIntervalSeconds` | 1 | `DeputyGameComponent` |
| 预热 | `WarmupJobsPerMinute` | 1 | `WarmupScheduler` |
| 日志 | `TraceEnabled` | 1 | `Trace` |

> `BaseUrl` / `Model` / `Voice` 有两个读者是**设计刻意**的：一个拍合成请求快照，一个供 `VoiceFingerprint` 计算。**派生点仍然只有一处**：`VoiceFingerprint` 只在 `SpeechLibrary` 里算。

### 6.2 固定项（无控件，不给用户改）

| 项 | 值 | 固定在哪 | 为什么没有控件（一句事实） |
|---|---|---|---|
| 输出格式 | `wav` | `TtsRequestParams.ResponseFormat` 常量 | 解码链只实现 WAV（`WavReader` 只认 RIFF/fmt/data） |
| 采样率 | 24 kHz 单声道 16 bit | 请求参数常量 | 库的容量核算（96 KB/2 s）与 WAV 解析都按这个口径 |
| 去重窗口 | 2000 ms | `Announcer.DedupeWindowMs` 常量 | 只对治 `Messages.AcceptsMessage` 的重复投递，不是听感参数 |
| 聚合边界 | 同 tick | `BatchAggregator` 判据 | 事件都在一瞬发生，窗口没有可调意义 |
| L1 软上限 | 500 条 | `LibraryJanitor.L1SoftLimit` 常量 | 只影响告警，不影响行为 |
| 预热队列上限 | 500 条 | `WarmupScheduler.WarmupQueueLimit` 常量 | 只影响预热的排队深度 |

## 7. 改一个字段只改一处（落点表）

| 需求 | 必须改的地方 | 不参与改动的模块 |
|---|---|---|
| 改某字段的**默认值** | `SetDefaults` 里那一行（类别开关改 `CategoryEntry.DefaultEnabled`） | 控件、读者模块 |
| 改某字段的**范围** | 该控件那一行的 min/max 常量 | `SetDefaults`、读者模块 |
| 改某字段**存到哪个键** | `ExposeData` 里那一行 | 字段声明、UI |
| 给某字段**换读者** | 旧读者删掉读取、新读者加读取 | 字段声明、UI、`SetDefaults` |
| **加一个新字段** | ①字段声明 ②`SetDefaults` 一行 ③`ExposeData` 一行 ④控件一行 ⑤读者一行（共 5 处，固定模板） | 其它页签、其它模块 |
| 加一类播报 | 见 `02` §2.2 的"新增一类播报" | 本页签的绘制代码（自动多一行） |
| 改某类别的 UI 文案 | `CategoryEntry.Label` / `Description` | 本页签的绘制代码 |

**自检**：打开任意一个字段，问"它的默认值/范围/存盘键/读者各有几个出处？"——答案必须都是 1。

## 9. 交互细节

| 项 | 规则 |
|---|---|
| 写盘时机 | 无「应用」按钮：控件改动的同一帧置脏，`DoWindowContents` 末尾 `FlushIfDirty()`；`PostClose` 再写一次 |
| 脏标记怎么来 | 控件走 `SetIfChanged(ref field, value)` 的四个重载（`string`/`float`/`int`/`bool`）；类别开关走 `SetCategoryEnabled`；两处都在"值真的变了"时置脏（原版 `GUI.Button` 不置 `GUI.changed`，所以脏标记靠比较新旧值）【实测】 |
| `恢复默认` | `ResetToDefaults()`：按 `CategoryEntry.DefaultEnabled` 与 `SetDefaults` 重设全部字段，然后置脏；**不关窗口** |
| `关闭` | `Close()`；窗口 `doCloseX = true`、`doCloseButton = false`、`forcePause = true`、`absorbInputAroundWindow = true` |
| 暂停语义 | 窗口打开时游戏暂停（`forcePause`），因此窗口内的"试听"不会与游戏内播报抢队列 |
| 滚动 | 只有播报类型页与调试页需要滚动；滚动位置是页签局部状态，不落盘 |
| 文本输入 | `BaseUrl` / `Model` / `Voice` / 手动朗读都用单行输入；不做格式校验（校验在 `TtsClient` 与 `SegmentPlanner`） |
| 掩码 | `ApiKey` 用 `GUI.PasswordField`，行下小字只显示末 4 位（`••••abcd`） |
| 只读区 | 缓存占用、最近播报、状态条一律只读，点不动 |

**状态条与失败呈现**

| 情形 | 状态条显示 | 数据来源 |
|---|---|---|
| 未配置（`BaseUrl` 或 `ApiKey` 为空） | `未配置 —— 不会播报` | `TtsClient.LastError.Message`（配置闸写的那条） |
| 已配置、无失败 | `已配置` | `TtsClient.LastError == null` |
| 最近一次请求失败 | `HTTP <状态码>：<响应体前 200 字>` | `TtsClient.LastError` |
| 点「试听」成功 | 播放「副官就位」，状态条回到 `已配置` | 播报链路与 `LastError` 清空 |
| 点「试听」失败 | 同一行立刻变成失败文案 | `TtsClient.LastError` |

- 状态条是唯一"后端可不可用"的显示处；**不做**额外的连通性探测请求。
- 失败文案保留到下一次成功请求为止（由 `TtsClient.LastError` 的更新时机决定）。
