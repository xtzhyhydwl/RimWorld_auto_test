## 必须知道的硬事实（踩过的，不要再踩）

1. **编译**：`dotnet build mods\副官语音\Source\VoiceDeputy.csproj`，
   但**必须先把 `DOTNET_CLI_HOME` 指到工作区内**（如 `tmp\dotnet-home`）。
   本机没有 net472 目标包也没有网络 ⇒ csproj 用 `NoStdLib` + 直接引游戏 `Managed\` 的程序集。
   **不需要** `build-mod.mjs`（那个脚本已删，也不需要恢复）。
2. **本会话 PowerShell/curl 的 HTTPS 全废**（Schannel 安全包缺失，连百度都连不上）。
   HTTPS 探测只能走 Python/Node。见 skill `环境陷阱.md` §七。
3. **SiliconFlow 返回的 WAV 长度字段是占位值**（`data size = 4294967040`）。
   直接喂给播放器会"Load 成功但没声音"。自写解析器必须按实际字节数重算。
   实测可播放样本：`runs\tts-probe\siliconflow-20261017-102109-fixed.wav`。
4. **`.cn` 域通、`.com` 用国内 key 返 401**。默认填 `https://api.siliconflow.cn/v1/audio/speech`。
5. **`0Harmony.dll` 在** `steamapps\workshop\content\294100\2009463077\1.6\Assemblies\`
   （旧 mod 的 csproj 写的是 `261550`，那是错的 appid）。第 3 步挂钩子时才需要它。
6. **`Messages.Message` 与 `LetterStack.ReceiveLetter` 各有多个重载**，Harmony 按名 patch 会抛
   `AmbiguousMatchException`，**必须写全参数类型**。

## 已定的设计决策（细节见文档，这里只给结论）

- **片段法**：一句话 = 有序片段，每片段独立合成、独立缓存。不做整句合成。
- **整句缓存**：作为"空闲预热的产物"做，排最后一步（可删的加速层，用来消拼缝）。
- **预热**：结构性必需（因为不引入旧预录，全走 TTS），顺序：固定短语 → 派系名 → 殖民者名。
- **聚合**：一群人同时出事播一句（"瘟疫，8 人感染，张三、李四…"）。**≤2 人点名，3 人以上只报数**。
- **语音库**：两个键空间（`segment` / `sentence`）+ **一套清理逻辑**；全局 LRU；三层保留等级
  （L1 骨架跨存档永不删 / L2 派系名+活人名 / L3 易变）；键带**音色指纹**与**存档作用域**。
- **存档标识**：自铸 GUID 存进存档（原版的 `WorldInfo.name/seedString` 同源，同种子重开会撞车）。
- **22 类播报开关**，开发期**默认全开**；加一类 = 改 enum + Catalog + UI 三处各一行，**不加 if**。
- **TTS 用户自填**（RimTalk 式），没填 key 就不出声，不做降级。
