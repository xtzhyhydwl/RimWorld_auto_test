## 硬约束（照做能省一轮返工）

1. **8 个补丁点，5 个文件**：`Messages.Message`、`LetterStack.ReceiveLetter`、`IncidentWorker.TryExecute`、`MentalStateHandler.TryStartMentalState`、`Hediff_Pregnant.StartLabor`、`Pawn_HealthTracker.MakeDowned`、`Pawn_HealthTracker.NotifyPlayerOfKilled`、`GenConstruct.PlaceBlueprintForBuild`。
2. **补丁必须写全参数类型**（这两个方法都有多重载，按名 patch 会 `AmbiguousMatchException`）。
3. **`GameComponent` 不注册**：写非抽象子类 + `public DeputyGameComponent(Game game)`，`Game.FillComponents()` 自动收养（见 `取证-GameComponent注册.md`）。
4. **死亡只挂一个点**：`NotifyPlayerOfKilled`（殖民者走信、囚犯/访客/远行队走消息，两支都从这里出）。
5. **一个事件只在一个通道播**：incident 是主分类器，其余通道按 def 丢弃重复项。不做"事件身份"，不做跨通道合并。
6. **中文只出现在 `SpeechCatalog`**；钩子只取事实、填参数，**不切分、不拼中文**；切分唯一归 `SegmentPlanner`。
7. **存储只落磁盘**，内存不常驻 `AudioClip`；等级与淘汰只归 `LibraryJanitor`（别的模块只读写，不删）。
8. **SiliconFlow 的 WAV 头长度字段是占位值**，解析必须按实际字节数重算（`WavReader`）。
