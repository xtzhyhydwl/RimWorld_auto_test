# 副官语音 v2 · 设置界面规格草案

> 状态：**草案，待用户批**。2026-10-17
> 依据：`docs/取证-提示信息出口.md`（钩子出口已确证）、`docs/调研-RimTalk接入模式.md`（配置模式）、
> SiliconFlow 官方 TTS 文档（2026-10-17 抓取）
> 用户定调（D7）：**先把界面做出来**，功能接不接得上另说；播不播完全由使用者决定。

## 0. 设计原则

1. **一个开关 = 一个使用者能自己回答的问题**。「要不要听袭击」能答；「要不要听 IncidentWorker.Postfix」不能答。
2. **界面先于功能**：所有开关都先接上、能存盘、能读回；后端接不上时按钮灰掉并写明原因，不静默失效。
3. **默认值要"安静可用"**：默认只开威胁与人身，其余默认关，避免一装就吵。
4. **未归类兜底默认关**：宁可漏，不可吵。

## 1. 窗口结构

- 原版 `Mod` 设置页里放一个按钮 **「打开副官语音设置」** → 打开自绘大窗口（内容太多，塞不进原版那一列）。
- 大窗口左侧竖向 4 个页签：**播报类型 / 语音 / 音量与节奏 / 调试**。
- 底部固定：`恢复默认`、`关闭`。改动即时写盘（不做"应用"按钮）。

## 2. 页签一：播报类型（核心）

每个条目 = `label + 开关 + 一句话说明`。分组可折叠。

| 组 | 条目 | 默认 | 数据来源 |
|---|---|---|---|
| **威胁** | 袭击（敌对/机械/虫巢） | 开 | incident + letter |
| | 围攻 / 空投 / 机械集群 | 开 | incident + letter |
| | 动物发狂 | 开 | incident + letter |
| **人身** | 殖民者倒地 | 开 | `Pawn.Notify_Downed` |
| | 殖民者死亡 | 开 | `Pawn.Kill` |
| | 精神崩溃 | 开 | `MentalStateHandler.TryStartMentalState` |
| | 分娩 / 婴儿出生 | 开 | `Hediff_Pregnant.StartLabor` + letter |
| **健康** | 疾病爆发（含感染者名单） | 开 | incident + letter |
| | 感染 / 瘟疫扩散 | 开 | letter |
| | 成瘾与戒断 | **关** | letter（噪声大） |
| **访客** | 商队抵达 | 开 | incident（需派系名 + 商人类型） |
| | 访客 / 难民 / 乞讨者 | 开 | incident + letter |
| | 任务与委托 | 开 | letter |
| **环境** | 极端天气（热浪/寒潮/火山冬天） | 开 | letter |
| | 太阳耀斑 / 日食 / 有毒落尘 / 辐射 | 开 | letter + message |
| | 物品腐烂 | **关** | `Messages`（`MessageRottedAwayInStorage`） |
| **建造与资源** | 蓝图缺材料（派生信号，播「缺 X 钢」） | **开** | 自己算（见 Q11） |
| | 落点失败（"这里不能放"） | **关** | `Messages`（`SilentInput`） |
| | 工作台缺料挂起 | **关** | 待取证（大概率不产生提示） |
| **兜底** | 其它事件（未归类 incident） | **关** | `IncidentWorker.TryExecute` |
| | 其它信件（未归类 letter） | **关** | `LetterStack.ReceiveLetter` |
| | 其它角落提示（未归类 message） | **关** | `Messages.Message` |

**粒度**：只到上表这一层，不做"逐个 defName 可勾"。理由：原版 1.6 有 100+ 个 IncidentDef，
逐个勾是维护地狱；上表 22 条覆盖了使用者真正会问的问题。要细化用"按组整体开关"即可。

**未决（见 §6）**：要不要给每条一个第三档「空闲才播」。

## 3. 页签二：语音（TTS 通道）

用户自填（D8）。**没填 key 就不出声**，界面顶部一条状态条：`未配置 —— 不会播报`。

| 字段 | 默认值 | 说明 |
|---|---|---|
| 服务地址（Base URL） | `https://api.siliconflow.cn/v1/audio/speech` | **实测（2026-10-17）**：`.cn` 通；`.com` 用同一把国内 key 返回 401。默认必须填 `.cn` |
| API Key | 空 | 掩码显示，`清空` 按钮，下方一行小字：**"明文存在本地 Config，别把 Config 发给别人"** |
| 模型 | `FunAudioLLM/CosyVoice2-0.5B` | 官方支持：`FunAudioLLM/CosyVoice2-0.5B`、`fishaudio/fish-speech-1.5` |
| 音色 | `FunAudioLLM/CosyVoice2-0.5B:alex` | **voice 必须带模型名前缀**（官方要求）。8 个预设：alex/benjamin/charles/david（男）、anna/bella/claire/diana（女） |
| 输出格式 | `wav` | 官方支持 mp3/opus/wav/pcm。**选 wav** 是为了少写一个解码器；采样率固定 24000 |
| 附加参数（JSON） | `{}` | 透传给请求体，可覆盖 `gain`（-10..10 dB）、`sample_rate` 等 |

**按钮**：`试听` —— 用当前配置合成"副官就位"，成功播出来、失败把 HTTP 状态码和响应体显示在按钮下方（**不要静默吞异常**）。
**连通性检查**：`试听` 即检查，不另做 `/v1/models`。

**协议形状**（实测自官方文档）：OpenAI 兼容 `POST {baseUrl}`，Header `Authorization: Bearer <key>`，
Body `{ model, input, voice, speed, response_format, sample_rate }`，返回**音频字节流**（不是 URL）。

## 4. 页签三：音量与节奏

| 字段 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 总音量 | 100% | 0–200% | 走 `AudioSource.volume`（D9：不折腾原版混音组） |
| TTS 音量 | 100% | 0–200% | 与预录分开，TTS 常常更响 |
| 预录音量 | 100% | 0–200% | |
| 语速 | 1.0 | 0.5–2.0 | 同时下发给 TTS（`speed`）与预录（`AudioSource.pitch`，**待验证音质**） |
| 合并窗口 | 2.0 s | 0–5 | 同窗口内的同类事件合成一句 |
| 队列上限 | 6 | 1–20 | 超出丢弃最旧的非威胁 |
| 威胁可打断 | 开 | — | 威胁类插队到当前播报之后立即播 |

## 5. 页签四：调试

| 字段 | 默认 | 说明 |
|---|---|---|
| 路径日志 | **关** | D11 的埋点：每个环节打 `[VD] 1` … `[VD] 6`、分支打 `5.1`/`5.2`，供自动化测试读 `Player.log` |
| 最近播报（只读） | — | 最近 20 条：时间 / 类型 / 原文 / 是否 TTS / 用时 ms |
| 手动朗读 | — | 文本框 + 按钮，绕过事件直接合成，用于调音色 |
| 缓存管理 | — | **必须**显示当前占用（条数 + 字节数，如 `1,234 条 / 12.3 MB`）；`清缓存` **必须同时清磁盘**（旧 mod 只清内存，是 bug） |

## 6. 未决（等用户答）

1. **每条要不要第三档「空闲才播」**（推荐：不要，二态足够；低优先级靠"兜底默认关"控制音量）。
2. **分类表是否要增减**（如"成瘾戒断""物品腐烂"默认关，是否符合你的预期）。
3. **语速用 `pitch` 调预录音频会不会变调失真** —— 要实听一次。
4. **SiliconFlow 国内域名**是 `.cn` 还是只有 `.com` —— 待核实（影响默认值）。
5. **API Key 落盘位置**：`Mod_<packageId>_<Settings>.xml`，明文。是否要额外做"环境变量优先"？推荐不做。
