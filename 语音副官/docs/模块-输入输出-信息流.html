01

六条不变量

改任何模块先对照这六条；它们就是「改一处」的支点。
I1只有 SegmentSynthesizer 跨线程：后台只拿 string/数值，只回 byte[]
违反：后台建 AudioClip、读 Pawn ⇒ 未定义行为
I2SpeechLibrary 是唯一碰磁盘音频的模块，且只在主线程被访问
违反：两处各写一半文件句柄
I3只有 LibraryJanitor 作删除决策，别人只能 ReportBroken 登记
违反：两套淘汰规则互相打脸
I4只有 Announcer 调 Switchboard；只有 TtsClient 判「配置是否可用」
违反：到处 if，加一类要改 N 处
I5文案只有一份：中文与分段规则都在 SpeechCatalog 的数据表里
违反：同一个词两种念法
I6音频唯一样子是磁盘文件 + AudioClip；无池、无 PCM 常驻
违反：3000 条 × 2 s ≈ 288 MB 常驻内存

VoiceDeputyMod

已有
输入

DeputyGameComponent

新增

输出

SegmentSynthesizer

新增

新增

持有

不负责

17

SpeechQueue

新增
输入
PlayableUtterance；PriorityOf(Category)；QueueLimit/ThreatInterrupts
输出
Peek() + MarkDone()（或 TryDequeue，二者选一并写明）
持有
只存未开始播的句子 + QueuedTick
不负责
不持「正在播的那句」（归 VoicePlayer）、不建 clip、不读文本；插队插到队首

VoicePlayer

新增
输入

PlayScheduled 出声；播完 WarmupScheduler.EnqueueSentence(FullText)；RecentSnapshot()
持有
AudioSource + dspTime 游标 + 当前句与 clip 游标 + 最近 20 条
不负责
不合成、不查开关、不判优先级、不认识缓存键、不删东西

新增

TtsRequest{Text, Params}（后台线程调用）

单条 SynthesisResult{JobId, Text, WavBytes?, Error?}；LastError 快照给 UI

04

13 个数据类型

跨模块流转的全部类型；字段只列关键项。
名字关键字段谁产出谁消费
Notice Category Phrase Args: string[] Names: string[] Count: int BatchKey: string? Tick: int · sealed class，数组只读不共享 5 个钩子文件 Announcer
SpeechPhrase enum：台词模板编号 → PhraseEntry{Template, ArgKinds} 钩子（选哪条说法） SegmentPlanner、SpeechCatalog
Segment Text: string Kind: SegmentKind · 常量 / 枚举 / 人名 / 数字 SegmentPlanner SegmentSynthesizer、ClipAssembler、LibraryJanitor
Utterance Segments: Segment[] FullText（计算属性） Category SegmentPlanner ClipAssembler.Plan、SegmentSynthesizer
PlayableUtterance Clips: AudioClip[] Category FullText FromSentenceCache: bool ClipAssembler SpeechQueue、VoicePlayer
BatchSummary Category BatchKey Count: int Names: string[] BatchAggregator SegmentPlanner.PlanBatch
LibraryEntry Key: LibraryKey{VoiceFingerprint, Scope, Text, SegmentKind} LastUsedTick Bytes: long · Scope 不落库，用时推 SpeechLibrary LibraryJanitor、UI
CategoryEntry Category Group/Label/Description Priority: int新增 Phrase新增 SpeechCatalog UI、SpeechQueue、SegmentPlanner
TtsRequestParams BaseUrl ApiKey Model Voice ResponseFormat Speed: float · 主线程拍的不可变快照 SegmentSynthesizer（主线程） TtsClient（后台）
TtsRequest Text: string Params: TtsRequestParams SegmentSynthesizer TtsClient（后台）
SynthesisResult JobId: long Text: string WavBytes: byte[]? Error: string? · 单条，批量由 Synthesizer 自己聚合 TtsClient（后台） SegmentSynthesizer.Drain（主线程）
WarmupJob Kind: 短语 | 整句 Text: string SegmentKind · 短语作业用 WarmupScheduler SegmentSynthesizer
PcmData Samples: float[] SampleRate: int Channels: int WavReader ClipAssembler → LoudnessNormalizer → AudioClip

名字不混用：SaveFingerprint 是存档 GUID（DeputyGameComponent 持有）；VoiceFingerprint 是 sha1(BaseUrl|Model|Voice)，只在键里出现。
